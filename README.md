A single-page web app for measuring expectancy-value beliefs about Artificial Intelligence use, grounded in Wigfield & Eccles' Expectancy-Value Theory.

✨ Features
20 research-based items across 5 motivational dimensions: Expectancy (Self-Efficacy), Attainment Value, Intrinsic Value, Utility Value, and Cost
Bilingual support — English 🇺🇸 & Spanish 🇪🇸 toggle
Informed consent screen & optional demographic questions (role, age, field, AI experience)
Interactive radar chart & animated score ring visualizing your EVQ profile
Google Sheets integration — responses are automatically logged with unique IDs & timestamps
Progress auto-save via localStorage
Accessible — ARIA labels, keyboard navigation, focus management
Downloadable PDF report & email sharing
Confetti celebration 🎉 on results
Fully responsive dark-themed UI with print-friendly styles
🛠 Tech Stack
HTML · CSS · Vanilla JavaScript · Google Apps Script

📖 Usage
Open 
index.html
 in any modern browser — no build step required.
